# Firo AI Support

A premium SaaS platform for AI chatbots trained on business documentation. Built with React, Framer Motion, and Base44 backend.

## ✨ Features

- **Landing Page** - Premium dark-themed homepage with hero section, live chat preview, features grid, pricing cards
- **Dashboard** - Manage chatbots, upload documents, view analytics
- **Mobile Ready** - WebView-optimized with bottom navigation, pull-to-refresh, safe area handling
- **Premium Design** - Glassmorphism cards, smooth animations, electric blue accents
- **Authentication** - Built-in auth with Base44
